# m5stack_stick_ping_monitor
Mini server IP monitor M5stack - StickS3 version


Monitor a network server or service in real time. You can listen to the response and also generate a report with the results.

Edit the "WIFI_SSID" and "WIFI_PASS" to connect your local network

Access the IP of device to set manual server IP and get the reports generated 

Use a buzzer connected to GND and G1 pin to get a audible response
